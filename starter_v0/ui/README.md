# Sổ Chi UI demo

Giao diện HTML/CSS/JavaScript thuần, dùng mock data trong `app.js`; không cần cài package.

Chạy từ thư mục này:

```bash
python -m http.server 4173
```

Mở `http://127.0.0.1:4173` trong trình duyệt.

Luồng demo chính: nhấn **Ghi giao dịch**, nhập khoản thu/chi, xem preview, rồi nhấn **Xác nhận và ghi**. UI sẽ cập nhật tổng quan, danh mục và nhật ký ngay trên trang.
